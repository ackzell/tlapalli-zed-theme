# Tlapalli Zed Theme

A monochromatic theme with 8 dark and 8 light colored variations. Inspired by minerals found in Mexico.

- **Dark:** Obsidian, Gold, Turquoise, Quartz, Lapis Lazuli, Amethyst, Jade, Fire Opal
- **Light:** Obsidian Light, Gold Light, Turquoise Light, Quartz Light, Lapis Lazuli Light, Amethyst Light, Jade Light, Fire Opal Light

## Installation

Search for **Tlapalli** in the Zed extensions panel, or clone this repo and use **Install Dev Extension**.

## Development

Theme colors are maintained in [tlapalli-vscode-theme](https://github.com/ackzell/tlapalli-vscode-theme). The Zed themes are generated from VS Code source files — run `./scripts/push-zed.sh` from that repo to sync.
